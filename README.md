# WebMapProject

WebMapProject is an interactive web application for the visualization and comparison of map projections. It enables users to explore how different cartographic projections transform the Earth's surface by providing synchronized 2D and 3D visualizations in real time. The application is developed in Julia using the Genie web framework, while Plotly.js is used for interactive graphics. Users can select among multiple projection types, adjust the central meridian and graticule spacing, and optionally display Tissot's Indicatrices to examine projection distortions. WebMapProject provides an interactive environment for exploring and comparing 13 different cartographic projections through synchronized 2D and 3D visualizations. Users can dynamically select a projection, adjust the central meridian, modify the graticule spacing, and optionally display both the geographic graticule and Tissot's Indicatrices. All visualizations are updated in real time without reloading the page, while Plotly's interactive controls allow users to zoom, pan, and rotate the 3D models for a more detailed examination of projection characteristics and distortions. The application is implemented entirely in Julia, which performs all cartographic calculations and projection transformations. The Genie Framework is used as the web server and routing engine, providing communication between the browser and the computational backend. Interactive maps are rendered using Plotly.js, while the user interface is built with HTML, CSS, and JavaScript, creating a responsive and intuitive web application that runs directly in a browser. This application was developed as part of a diploma thesis to provide an educational and interactive environment for studying cartographic projections and their geometric distortions. It allows users to better understand the differences between projection families and to visually analyze distortions of shape, area, distance, and direction through dynamic map exploration.
