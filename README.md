# WebMapProject

WebMapProject: Interactive Visualization of Cartographic Projections

WebMapProject is a web-based application designed for the generation, visualization, and comparative analysis of cartographic projections in two-dimensional (2D) and three-dimensional (3D) environments. The application supports 13 cartographic projections, including cylindrical, conic, azimuthal, and transverse projections.
 
Additionally, WebMapProject supports the visualization of cartographic projections using geographic coastline datasets. It provides interactive controls for modifying the central meridian, adjusting geographic graticule intervals, and displaying Tissot's indicatrices for the examination of cartographic distortions. The application presents simultaneous 2D and 3D representations, allowing users to explore the geometric characteristics of different map projections.

WebMapProject has been developed using the Julia programming language and the Genie Framework, while its graphical interface is implemented using HTML, CSS, and JavaScript. Interactive visualizations are generated using Plotly.js.

WebMapProject has been developed as part of a diploma thesis at the Department of Surveying and Geoinformatics Engineering of the University of West Attica, with the aim of supporting cartographic education and facilitating the understanding of map projections and their associated distortions.
